Netzwerk

Simulation mit WebNetSim

  1. Klicke den Link dreimal an und öffne die Internetseite WebNetSim in drei verschiedenen Tabs.
    Webnetsim.de
  2. Klicke jeweils auf Starten
  3. Aktiviere im folgenden Fenster jeweils den Netzwerkproblem-Modus.
  4. Wähle für jedes Tab einen anderen Modus:
    1. Haushalt
    2. Provider
    3. Website Anbieter

Haushalt

  1. Verbinde deinen Router mit deinem Provider
  2. Füge folgende Geräte deinem Heimnetz hinzu:
    1. Computer
    2. Handy
    3. Drucker

Provider

Füge folgende Geräte deinem Provider-Netz hinzu: 1. DNS-Server

Website Anbieter

  1. Verbinde den Router mit deinem Provider
  2. Füge folgende Geräte deinem lokalen Netzwerk hinzu:
    1. 5 Webserver, die jeweils eine andere Internetseite hosten

Aufgaben

Klicke im Haushalt auf Aufgaben und versuche sie der Reihe nach zu lösen.
