# Internetseite im Github Pages erstellen

1. Registriere dich bei Github und logge dich ein.
2. Erstelle ein neues Repository (rechts oben: + anklicken -> "New Repository")
3. Benenne das Repository nach folgendem Muster:
    **username.github.io**
    Ersetze hierbei **username** durch deinen Benutzernamen bei github
4. Erstelle eine erste Readme-Datei, indem du a "Initialize this repository with a README" wählst und auf "Create repository" klickst.
5. Erstelle im Verzeichnis des neuen Repositories die Internetdateien, die du anzeigen willst.
