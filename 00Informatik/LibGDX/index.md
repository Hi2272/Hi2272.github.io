# LibGDX: Game Design in Java
## Allgemeines
LibGDX ist eine OpenSource Game Engine für Java.

## Installation
### BlueJ
Um LibGDX unter BlueJ zu verwenden, muss im Projektordner ein Verzeichnis +libs angelegt werden.
In diesem Verzeichnis müssen folgende jar-Dateien enthalten sein:
- gdx.jar
- gdx-backend-lwjgl.jar
- gdx-backend-lwjgl-natives.jar
- gdx-natives.jar
- gdx-sources.jar
